# SMP Plus Ibadurrahman Website

Website resmi SMP Plus Ibadurrahman - Sekolah Menengah Pertama yang berkomitmen dalam mengembangkan prestasi akademik dan karakter islami.

## 🎓 Tentang Kami

SMP Plus Ibadurrahman adalah sekolah menengah pertama swasta yang menyatukan pendidikan akademik berkualitas dengan pembentukan karakter islami. Kami berkomitmen menciptakan generasi yang cerdas, disiplin, dan siap menghadapi masa depan.

## 🌟 Fitur Website

- **Halaman Beranda**: Tampilan utama dengan ringkasan program dan fasilitas
- **Profil Sekolah**: Informasi visi, misi, dan identitas sekolah
- **Program Unggulan**: Daftar program akademik dan ekstrakurikuler
- **Berita & Kegiatan**: Update terbaru tentang aktivitas sekolah
- **Kontak & Pendaftaran**: Form hubungi dan informasi pendaftaran
- **Responsive Design**: Kompatibel dengan desktop dan mobile
- **SEO Optimized**: Dioptimalkan untuk search engine

## 📱 Teknologi

- HTML5
- CSS3 (dengan CSS Variables)
- JavaScript vanilla (tanpa framework)
- Responsive Grid Layout

## 📋 Halaman Tersedia

- `index.html` - Beranda
- `profil.html` - Profil Sekolah
- `program.html` - Program Unggulan
- `berita.html` - Berita & Kegiatan
- `kontak.html` - Kontak & Pendaftaran
- `404.html` - Halaman Error

## 🚀 Cara Menggunakan

1. Download atau clone repository ini
2. Buka file `index.html` di browser
3. Navigasi menggunakan menu di header
4. Edit informasi sekolah sesuai kebutuhan

## ⚙️ Kustomisasi

Untuk mengubah informasi sekolah:

1. **Warna**: Edit variable CSS di bagian `:root` dalam `style.css`
2. **Konten**: Edit text di setiap file HTML
3. **Logo**: Ganti URL di class `.logo` atau tambahkan gambar
4. **Kontak**: Update informasi di footer semua halaman

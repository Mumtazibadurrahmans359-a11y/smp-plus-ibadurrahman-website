2. Koneksikan ke GitHub Pages atau hosting lain
3. Update metadata di tag <head> masing-masing HTML

# Analytics
Untuk menambahkan Google Analytics, tambahkan kode di tag <head>:
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>
```
